# PhotoWall 光影墙

一款以照片墙为核心视觉的 [Typecho](http://typecho.org) 主题：把文章、分类、标签转化为照片墙数据源，支持单图轮播、多图网格、分类/标签筛选与 Lightbox 大图预览。适合摄影博客、旅行记录、作品集与图库站点。

- **单图模式**：全屏大图轮播，渐入渐出 / 随机淡入 / 缩放 / 滑动 / Ken Burns 缓慢推近
- **多图模式**：网格照片墙，随机替换卡片、淡入淡出、位置流动
- **混合模式**：上方大图 + 下方网格
- **筛选**：分类 / 标签按钮一键切换照片范围，支持 `?category=slug`、`?tag=slug` 分享链接
- **Lightbox**：键盘（Esc / ←→ / +-）、手势（滑动切换、双指缩放、下拉关闭）、信息栏（标题 / 描述 / 分类 / 标签 / 日期）、下载 / 原图 / 分享 / 跳转文章
- **性能**：图片懒加载、首屏预加载、比例占位防抖动、照片池文件缓存、AJAX 接口
- **SEO**：JSON-LD `ImageGallery`、Open Graph、canonical、noscript 回退网格
- **无障碍**：键盘可操作、焦点管理、ARIA 标签、`prefers-reduced-motion` 支持

## 环境要求

| 项目 | 要求 |
|---|---|
| Typecho | 1.2.x / 1.3.x |
| PHP | 7.4 - 8.2（需 mbstring） |
| 数据库 | MySQL / SQLite |
| 浏览器 | Chrome / Firefox / Safari / Edge（含移动端） |

## 安装

1. 将 `PhotoWall` 文件夹上传到 Typecho 的 `usr/themes/` 目录；
2. 后台「控制台 → 外观」启用 **PhotoWall 光影墙**；
3. 「外观设置」按需调整，默认配置即可开箱可用。

## 快速上手

1. 写文章时在编辑器「自定义字段」里填 `cover`（封面图 URL）；多图文章每行一个 URL 填进 `photos`；
2. 给文章设置分类和标签，照片墙筛选按钮会自动生成；
3. 后台「外观设置 → 布局」选择展示模式（单图 / 多图 / 混合）。

## 自定义字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `cover` | 文本 | 照片墙封面图 URL（支持 HTTP(S) 与站内根相对地址） |
| `photos` | 多行文本 | 多图列表，每行一个 URL |
| `thumb` | 文本 | 卡片缩略图 URL，留空用原图 |
| `description` | 文本 | 照片描述，留空时截取正文前 140 字 |
| `ratio` | 选择 | 卡片比例：`1:1` / `4:3` / `3:2` / `16:9`，留空跟随主题设置 |
| `hide` | 选择 | 填 `1` 将文章从照片墙隐藏（文章本身仍可访问） |

**图片提取优先级**：`cover` / `photos` 字段 → 文章附件中的图片 → 正文第一张 `<img>` → 默认占位图。

## 照片数据接口

主题内置 JSON 接口（可在「高级设置」关闭）：

```
/?pw-api=1&category=travel&tag=&page=1&limit=20&orderby=date
```

| 参数 | 说明 |
|---|---|
| `category` | 分类 slug（白名单：字母数字、`-`、`_`） |
| `tag` | 标签 slug |
| `page` / `limit` | 分页（limit 上限 100） |
| `orderby` | `date`（默认）或 `random` |

返回 `{code, message, data: {items, total, page, limit}}`。当照片数超过「AJAX 启用阈值」时，前端会自动改为通过该接口分页拉取数据。

## URL 参数

- `?category=travel` — 打开时自动筛选该分类
- `?tag=sunset` — 打开时自动筛选该标签
- 切换筛选按钮时地址栏会同步更新，方便分享

## 缓存说明

- 照片池数据缓存为 JSON 文件：优先 `PhotoWall/cache/`，目录不可写时回退系统临时目录；
- 缓存键包含内容表指纹（文章数 + 最新创建时间），发布 / 编辑 / 删除文章后自动失效；
- 后台「性能设置」可关闭缓存或调整 TTL。

## 常见问题

**Q：照片墙不显示图片？**
确认文章有自定义字段 `cover`/`photos`，或正文里包含 `<img>`，或存在图片附件；都没有时显示占位图。

**Q：筛选按钮太多？**
在「筛选设置」里限制最大数量，超出部分自动隐藏。

**Q：如何让某篇文章不进照片墙？**
编辑文章，把「照片墙可见性」设为「从照片墙隐藏」。

**Q：Lightbox 打不开？**
检查「弹窗设置 → 启用 Lightbox」是否开启；关闭时点击图片会直接跳转文章。
