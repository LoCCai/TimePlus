# PhotoWall 光影墙

一款以照片墙为核心视觉的 [Typecho](http://typecho.org) 主题：把文章、分类、标签转化为照片墙数据源，支持单图轮播、多图网格、分类/标签筛选与 Lightbox 大图预览。

> 开发中（v1.0.0），完整使用文档将在发布时补充。

## 环境要求

- Typecho 1.2.x / 1.3.x
- PHP 7.4 - 8.2
- MySQL / SQLite

## 快速开始

1. 下载本目录为 `PhotoWall` 文件夹；
2. 放入 Typecho 的 `usr/themes/` 目录；
3. 后台「控制台 → 外观」启用 **PhotoWall 光影墙**；
4. 在后台「外观设置」按需调整（默认配置即可开箱可用）。

## 自定义字段

编辑文章时可在「自定义字段」中填写（启用主题后编辑器会出现对应字段）：

| 字段 | 说明 |
|---|---|
| `cover` | 照片墙封面图 URL |
| `photos` | 多图列表，每行一个 URL |
| `thumb` | 卡片缩略图 URL（留空用原图） |
| `description` | 照片描述（留空截取正文） |
| `ratio` | 卡片比例：`1:1` `4:3` `3:2` `16:9`（留空跟随主题设置） |
| `hide` | 填 `1` 将文章从照片墙隐藏 |

图片提取优先级：`cover` / `photos` 字段 → 文章附件 → 正文首图 → 占位图。
