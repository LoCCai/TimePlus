# Changelog

## 1.0.0 (2026-09-14)

首个正式版本。

### 新增

- 照片墙首页：单图轮播 / 多图网格 / 混合模式三种展示
- 过渡效果：渐入渐出、随机淡入、缩放渐入、滑动切换、Ken Burns、随机组合
- 轮播控制：间隔 / 时长 / 缓动可配，随机顺序、悬停暂停、页面不可见暂停、移动端降动效、`prefers-reduced-motion`
- 分类 / 标签筛选按钮，URL 参数（`?category=` / `?tag=`）与地址栏同步
- 零依赖 Lightbox：键盘导航、滚轮 / 双指缩放、拖拽平移、滑动切换、下拉关闭、焦点管理、历史记录整合
- 图片提取链：自定义字段 → 文章附件 → 正文首图 → 占位图
- 后台设置面板（基础 / 布局 / 动效 / 筛选 / 弹窗 / 性能 / SEO / 高级）与文章自定义字段
- JSON API：`/?pw-api=1`，支持分类 / 标签 / 分页 / 排序，超过阈值时前端自动启用
- 性能：懒加载、首屏预加载、比例占位、照片池文件缓存（内容指纹自动失效）
- SEO：JSON-LD ImageGallery、Open Graph、canonical、noscript 回退网格
- 配色：自动 / 深色 / 浅色，访客可切换并记忆
